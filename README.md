# Hamim - Shipping & Delivery Marketplace App

Hamim is a mobile shipping and delivery marketplace built with Flutter for the Saudi market. The app connects customers who need to send or receive shipments with transport providers that can submit price offers based on shipment details, vehicle type, location, and availability.

> Note: This repository is shared as a public case study only. Source code and proprietary implementation details are not included due to NDA restrictions.

## Overview

The application supports two main user flows: customers and transport companies. Customers can create shipment requests, choose vehicle and shipment types, upload shipment photos, select pickup and delivery locations, and compare provider offers. Transport companies can manage their profile, register vehicles, receive matching orders, send price offers, and update order status through the delivery lifecycle.

## Key Features

- Customer and provider onboarding
- Phone number authentication with OTP
- Shipment creation for sending and receiving orders
- Pickup and delivery location selection
- Vehicle type and shipment type selection
- Shipment image upload
- Provider matching based on vehicle type and location
- Offer submission and acceptance workflow
- Company vehicle management
- Order status tracking
- Rating system for providers
- Arabic and English localization
- Firebase-backed authentication, database, and storage

## Tech Stack

- Flutter / Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase App Check
- BLoC / Cubit state management
- Flutter localization
- Android and iOS support
